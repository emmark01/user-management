# User Management

React admin app for a workspace user directory. Browse people, create and edit accounts, filter by role and status, and review access roles.

## Stack

- React 19 + TypeScript
- Vite
- React Router

## Scripts

```bash
npm install
npm run dev
npm run build
npm test
```

Open the local Vite URL, then use Dashboard, Users, Roles, and Settings. Sample data lives in memory and resets on refresh.
